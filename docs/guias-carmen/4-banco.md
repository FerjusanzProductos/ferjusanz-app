# 🏦 Revisar el banco
Cuando tengas el fichero del banco. La app propone de quién es cada movimiento; tú lo confirmas.

1. En «Facturas y análisis», pulsa **«Banco»**. [foto: banco-1]
2. Pulsa **«Subir fichero del banco»** y elige el fichero que descargas de la web del banco (Norma 43 o Excel). [foto: banco-2]
3. Toca cada movimiento **sin confirmar**. [foto: banco-3]
4. Lee la **propuesta de la app**. Si no es correcta, cambia cliente, proveedor u «Otro» y la factura que paga. [foto: banco-4]
5. Pulsa **«Confirmar»**. [foto: banco-5]

> Si subes **dos veces el mismo fichero**, no se repite nada.
> Si el importe coincide con una factura de cliente, la factura queda **cobrada** sola.
> Si el importe **no cuadra**, la app avisa: no lo fuerces, pregunta a Fernando.
