# 08 · Textos para empezar chats

## Para qué sirve
Textos que se pegan como **primer mensaje** en un chat nuevo de Claude para que entienda la empresa desde el principio.

| Archivo | Para quién | Dónde se pega |
|---|---|---|
| `PROMPT_FERNANDO_NUEVO_CHAT.md` | Fernando | Sesión nueva de Claude Code (entorno «ferjusanz-app») |
| `PROMPT_EQUIPO.md` | Cristian, Carmen y Juli | Chat normal de Claude (claude.ai o la app) |
| `PROMPTS.md` | Fernando | Encargar uno de los 8 agentes o mejoras pedidas (bloque «Contexto» + la tarea) |

> Nota: en Claude Code ya no hace falta pegar el contexto: Claude lee `CLAUDE.md` y `docs/` solo.
> `PROMPT_FERNANDO_NUEVO_CHAT.md` tiene datos antiguos (p. ej. ramas y «GitHub suspendido»); manda lo de `docs/ESTADO_ACTUAL.md`.

## Tareas que hace Claude aquí
- Mantener estos textos al día cuando cambian reglas, precios o pantallas de la app.
- Ayudar al equipo (con `PROMPT_EQUIPO.md`) a usar la app y a escribir mensajes a clientes, **sin precios** salvo los que apruebes.
